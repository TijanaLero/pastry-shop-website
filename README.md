# 🍰 Pastry Shop Website

A responsive website created for a fictional local pastry shop, designed to showcase products, brand story, and contact information in a clean and visually appealing way.

The project focuses on simplicity, readability, and modern web design principles, making it suitable as a small business presentation website.

---

## 🧩 Overview

This project represents a **fictional local pastry shop website** developed as a web design project.

The website presents the shop’s assortment of cakes, pastries, and desserts, allows users to learn more about the brand, and includes a contact form for placing inquiries or orders.

---

## ✨ Features

- Fully responsive design (mobile, tablet, desktop)
- Clean and modern UI using Bootstrap
- Navigation bar for easy page access
- Product gallery section
- Contact form with client-side validation
- Interactive success alert after form submission

---

## 🛠️ Technologies

- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **JavaScript**
  - Form validation using Bootstrap validation API
  - Dynamic alert messages for user feedback

---

## 📄 How to Run the Project

1. Clone the repository
2. Open `index.html` in your browser

No additional setup or dependencies are required.
