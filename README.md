# Pastry Shop Website

A responsive, multi-page website created for a fictional local pastry shop.  
The project is designed as a small business presentation website, focusing on clean layout, usability, and visually appealing product presentation.

The website showcases the pastry shop’s assortment, brand values, special offers, and provides a functional ordering and contact form with client-side validation.

---

## Project Overview

This project represents a fictional pastry shop website developed as a front-end web project using modern web technologies.

The website includes:
- A landing page with brand introduction and featured sections
- A product listing page presenting cakes and cupcakes
- An ordering/contact page with a validated form and user feedback
- Responsive layout optimized for different screen sizes

The main goal of the project was to practice responsive design, layout structuring with Bootstrap, and basic JavaScript interactivity.

---

## Pages

- **Home (index.html)**  
  Landing page with hero section, features, product carousel, team section, pricing packages, and footer.

- **Products (ponuda.html)**  
  Product catalog displaying cakes and cupcakes using Bootstrap cards and responsive grid layout.

- **Ordering / Contact (forma.html)**  
  Page containing an order and inquiry form with client-side validation and dynamic alert messages.

---

## Features

- Fully responsive design (mobile, tablet, desktop)
- Multi-page website structure
- Clean and modern UI built with Bootstrap 5
- Responsive navigation bar with collapsible menu
- Product carousel showcasing featured items
- Product listing using Bootstrap cards and grid system
- HTML5 video background on the ordering page
- Contact and ordering form with:
  - HTML5 form validation
  - Bootstrap validation styling
  - JavaScript-based validation handling
  - Dynamic success alert message after submission
- Consistent footer across all pages
